# BiStudent — сайт статистики

Распакуйте ZIP и загрузите эту папку через Netlify Drop / Deploy manually. `index.html` должен находиться в корне опубликованной папки. Сборка, npm и сервер не нужны. Подойдёт любой статический хостинг с HTTPS.

Сайт уже подключён к проекту Firebase `bistudent`, документу `publicStats/23-po-103-4r-2`. Посетители не регистрируются. В браузере нет паролей преподавателя, токенов или ключей администратора.

При первом открытии выполняется один GET к Firestore, который возвращает весь снимок статистики. Ответ хранится в localStorage **60 секунд**. При повторном открытии или обновлении страницы до истечения этого срока запросов к Firebase нет. После истечения срока следующее открытие делает один GET. Вкладки используют общий кэш и блокировку, если браузер её поддерживает. Поиск, выбор предмета и переключение вкладок работают локально. Фонового опроса Firebase нет. При ошибке сети последняя копия остаётся доступной, повторные запросы ограничены паузой 30 секунд. Интервал можно изменить в `config.js`.

Приложение преподавателя публикует отдельный снимок оценок и посещаемости после изменений. Публичный просмотр не читает авторизацию и образцы лиц. Отдельная страница регистрации создаёт приватную отправку по индивидуальному коду. Используйте обновлённую сборку приложения с поддержкой сайта.

Среднее группы — сумма всех оценок, делённая на количество оценок. График показывает накопительный средний по датам. Пустые оценки не учитываются. В таблице оценок видны все сохранённые баллы; дата доступна при наведении. Вкладка посещаемости показывает сохранённые отметки присутствия. Отсутствие отметки не приравнивается к прогулу.

Если оценок нет, график показывает волну ровно по центру и подпись «Пока данных нет». Если в выбранном разделе нет записей, таблица показывает «Данных нет». Данные студентов и оценки не зашиты в файлы сайта: они читаются из Firebase.

## Регистрация лица по индивидуальному коду

В новой версии есть `register.html`: ссылка «Зарегистрировать лицо» на главной странице. Преподаватель выдаёт код в приложении BiStudent для выбранного студента. Код действует 24 часа и используется один раз. При выпуске нового кода предыдущие коды того же студента отключаются.

Студент вводит код, разрешает камеру, выбирает устройство, делает три снимка и отправляет их. Регистрация аккаунта и пароль не нужны. Снимки хранятся в закрытой коллекции Firebase. Приложение преподавателя получает их при входе или ручном обновлении из Firebase; оно проверяет и выравнивает лицо, затем сохраняет образцы для остальных устройств.

Для камеры нужен HTTPS или localhost; Netlify предоставляет HTTPS. При открытии ZIP через file:// камера и работа сайта не гарантируются. Сайт остаётся без сборки, сторонних библиотек и секретов. `_headers` разрешает камеру только этому сайту, микрофон отключён.

Перед использованием должны быть опубликованы актуальные `firestore.rules` из проекта: они содержат новый UID преподавателя, faces, faceInvites и faceSubmissions. Старые ZIP приложения с предыдущим UID больше не подходят.
